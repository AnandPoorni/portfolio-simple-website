About the Project

This is my personal portfolio website, created using HTML and CSS as part of my web development learning journey. It showcases my introduction, interests, projects, and contact information through a simple and clean design.

The website consists of two pages: a Home page and a Contact page.

Pages

Home Page: Introduces me as a Web Developer and includes an About Me section, my interests, my projects, and social media links.

Contact Page: Contains a contact form with fields for name, email, and message, allowing visitors to enter their details.

Clone or download this repository.

Navigate to the Contact page using the Contact link.
